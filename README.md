# NESYAN — متجر نسيان للعطور

متجر عطور فاخر بالعربي والإنجليزي، معمول بـ **Vite + React**، ومعاه **لوحة تحكم** (`/admin`) شغالة على **Supabase**.

> الموقع بيشتغل حتى من غير Supabase، وبيعرض العطور والمحتوى الافتراضي الموجود في `src/data/defaults.js`.
> لوحة التحكم والطلبات والرسائل بس هي اللي محتاجة Supabase.

## 1) التشغيل على جهازك
```bash
npm install
npm run dev
```
وبعدها افتحي `http://localhost:5173`.

## 2) Supabase (مرة واحدة)
1. اعملي **مشروع جديد خاص بنسيان**. ما تستخدميش مشروع ركويزا ولا البورتفوليو، عشان الجداول ليها نفس الأسامي.
2. من **SQL Editor** افتحي **New query**، والزقي ملف `supabase/schema.sql` كله، واضغطي **Run**.
3. من **Authentication → Users → Add user** اعملي يوزر بإيميلك، وعلّمي على **Auto Confirm**.
4. شغّلي السطر ده بإيميلك:
   ```sql
   insert into public.admin_users (user_id) select id from auth.users where lower(email) = lower('your-email@example.com');
   ```
5. اعملي ملف `.env` جنب `package.json`، وحطي فيه القيم من **Project Settings → API Keys**:
   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=sb_publishable_xxxx
   ```
   ⚠️ استخدمي الـ **publishable** بس. ممنوع تحطي الـ `secret` أو `service_role` في أي مكان.

## 3) Vercel
1. ارفعي المشروع على GitHub.
2. اختاري Framework Preset **Vite**.
3. ضيفي المتغيرين في **Environment Variables**، وبعدين اعملي **Deploy**.

## لوحة التحكم
| القسم | بيتحكم في |
|---|---|
| **الطلبات** | كل طلب بالمنتجات والعنوان والإجمالي. تقدري تغيري الحالة (جديد ← تم التأكيد ← تم الشحن ← تم التسليم / ملغي)، وتفتحي واتساب العميل، وتصدّري Excel |
| **العطور** | إضافة وتعديل وحذف وترتيب العطور: صورة الزجاجة، صورة العلبة (اللي بتظهر لما تلمسي الكارت)، صور إضافية، الأحجام والأسعار والخصم، النوتات، الحكاية، الثبات والفوحان، وعلامات جديد / الأكثر مبيعًا / حصري / متوفر |
| **الرسائل** | رسائل صفحة التواصل وإيميلات النشرة البريدية |
| **الصفحة الرئيسية** | ترتيب الأقسام وإخفاؤها، وكل نصوص وصور السكشنات |
| **إعدادات المتجر** | مصاريف الشحن، حد الشحن المجاني، بيانات التواصل والواتساب، والسوشيال ميديا |

## الأسعار
الأسعار لسه مش متحطوطة، فكل عطر مكتوب عليه «السعر عند الطلب»، والطلب بيروح على واتساب.
لما تكتبي السعر في «الأحجام والأسعار» من صفحة العطر في اللوحة، هيظهر زرار «أضف للسلة» وصفحة إتمام الطلب لوحدهم.

## ملحوظة عن الصور
صور الزجاجات والعلب والمشاهد الموجودة دلوقتي **صور مؤقتة**. غيّريها بصور العطور الحقيقية من لوحة التحكم:
- **العطور:** افتحي العطر ← تعديل ← رفع صورة.
- **السكشنات:** من الصفحة الرئيسية في اللوحة.

الأفضل صور PNG أو WEBP بخلفية شفافة أو فاتحة، ومقاس طولي زي 800×1000.
