طريقة الرفع (مهم):
1) امسحي كل الملفات اللي جوه فولدر المشروع عندك ما عدا: .git  و  node_modules  و  .env
2) فكّي الملف ده، والزقي كل اللي فيه جوه فولدر المشروع على طول (جنب .git)
   لازم يبقى package.json و src و public في أول الفولدر — مش جوه فولدر nesyan تاني
3) في التيرمنال:
   git add -A
   git commit -m "all updates"
   git push
